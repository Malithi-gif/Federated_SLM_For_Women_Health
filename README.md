# Secure Federated SLMs for Women’s Health

Updated GitHub Pages website for:

**Secure Federated LoRA Fine-Tuning of Small Language Models for Women’s Health Support on Consumer Devices**

## Files

- `index.html` — professional research landing page
- `style.css` — responsive styling
- `script.js` — interactive results comparison
- `demo.html` — static interface demonstration
- `assets/framework.png` — proposed framework figure
- `assets/efficiency.png` — efficiency comparison figure
- `assets/communication.png` — PQC communication figure

## Deployment

Copy all files and the `assets` folder to the repository root, then run:

```bash
git add .
git commit -m "Improve GitHub Pages research website"
git push origin main
```

The demo is an interface illustration and does not load a trained model.
